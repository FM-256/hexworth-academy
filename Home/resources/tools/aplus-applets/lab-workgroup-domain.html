Exercise 2: Command Line Network Info

▼
1 Open Command Prompt
Search for "cmd", right-click Command Prompt, and select "Run as administrator"
2 Hostname Commands
Run the following commands and record the output:
hostname
whoami
3 Network Configuration
Run the following command to view domain/workgroup information:
systeminfo | findstr /B /C:"Domain"
net config workstation
