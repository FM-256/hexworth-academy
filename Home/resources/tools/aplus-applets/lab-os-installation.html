Lab: OS Installation Preparation

Estimated Time 45-60 minutes
Difficulty Beginner-Intermediate
Prerequisites Windows 10/11, USB (8GB+) optional

Lab Objectives

  • Verify system requirements for OS installation
  • Understand boot configuration (UEFI/BIOS)
  • Explore partitioning and disk management
  • Practice using Windows recovery options
  • Prepare for installation scenarios

Exercise 1: System Requirements Check

▼
1 Check Windows 11 Compatibility
Navigate to Settings > System > Windows Update and check for Windows 11 compatibility, or run the PC Health Check app if available.
2 View System Type
Determine whether your system is 32-bit or 64-bit architecture.

Exercise 2: UEFI/BIOS Exploration

▼
1 Identify Boot Mode
Open System Information to identify your boot mode: Press Win+R, type msinfo32, and press Enter.
2 Boot Configuration
Open Command Prompt as Administrator and run: bcdedit
Warning: Don't modify bcdedit unless you know what you're doing! Incorrect changes can prevent your system from booting.

Exercise 3: Disk and Partition Analysis

▼

Note: GPT is required for UEFI boot and supports drives larger than 2TB. MBR is legacy and limited to 2TB.

Exercise 4: Recovery Environment

▼
1 Access Windows Recovery
Navigate to Settings > System > Recovery (Windows 11), or Settings > Update & Security > Recovery (Windows 10).
2 View Recovery Options
Examine the available recovery options (DO NOT actually reset your PC during this lab).
Warning: Do NOT use "Reset this PC" on a production computer during this lab! Only explore the options.
3 Advanced Startup
Locate the "Advanced startup" section. DO NOT restart unless you're in a test environment.
