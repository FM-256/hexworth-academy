Task 3: Search for Logon Events

  • Navigate to Windows Logs > Security
  • Use Filter Current Log or Find to locate Event ID 4624 (successful logon)
  • Record when you last logged on to the system
If you don't see Event ID 4624 events, auditing may be disabled on your system. This is common on Home editions or systems without audit policies configured.

Exercise 6: Performance Monitor Quick Look

Task 1: View Real-Time Performance

  • Press Win+R and run perfmon.msc
  • Observe the default graph showing % Processor Time
  • In the left pane, expand Monitoring Tools and click "Performance Monitor"
  • Click the green "+" button to see available counters (DON'T add, just browse)
  • From the top menu or Action, open Resource Monitor (or run resmon)
