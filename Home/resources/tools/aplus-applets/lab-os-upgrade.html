Lab: OS Upgrade Planning and Verification

Estimated Time 45-60 minutes
Difficulty Intermediate
Prerequisites Windows 10/11 computer

Lab Objectives

  • Verify system meets upgrade requirements
  • Check application compatibility
  • Create backup documentation
  • Explore upgrade and rollback options
  • Practice pre-upgrade checklist

Exercise 1: System Requirements Verification

▼
1 Run PC Health Check (for Windows 11)
Download and run the PC Health Check tool from Microsoft, or check requirements manually using the following steps.
2 Check Specific Requirements
Verify your system meets the minimum hardware requirements for upgrade.
3 Document Current OS
Record information about your current Windows installation.

Exercise 2: Compatibility Assessment

▼
1 Check Installed Applications
Review your installed applications to identify potential compatibility issues.
2 Driver Inventory
Check Device Manager for any hardware issues that might affect the upgrade.
3 Known Incompatibilities
Note: Older applications may not work after upgrading. Check manufacturer websites for compatibility information before proceeding with any upgrade.
WARNING: Do NOT proceed with an actual upgrade during this lab. We are only preparing and documenting.

Exercise 3: Backup Documentation

▼
1 Identify Data to Backup
Document the locations and status of your important data.
2 Record Important Settings
Document current system settings that you may need to reconfigure after an upgrade.
3 License Key Inventory
Note: Store license keys in a safe location before any upgrade. Use tools like ProduKey or Belarc Advisor to find them.

Exercise 4: Explore Upgrade Options

▼
1 Check Windows Update
Navigate to Settings > Windows Update to see available updates.
2 Understand Upgrade Paths
Test your knowledge of Windows upgrade paths.
3 Media Creation Tool (Research Only)
Answer questions about the Windows Media Creation Tool.

Exercise 5: Recovery Options

▼
1 View Recovery Settings
Navigate to Settings > System > Recovery to view available recovery options.
2 Windows.old Folder
Check if the Windows.old folder exists on your C: drive.
3 Create Recovery Drive (Documentation Only)
Answer questions about creating a Windows recovery drive.

Exercise 6: Pre-Upgrade Checklist Completion

▼
1 Final Verification (Check All That Apply)
Confirm you have completed all pre-upgrade preparation steps.
2 Post-Upgrade Plan
Document your plan for verifying the upgrade was successful.
3 Rollback Plan
Document your understanding of the rollback process.
