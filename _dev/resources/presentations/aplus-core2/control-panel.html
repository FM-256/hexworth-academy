Control Panel Overview

What is Control Panel?

Legacy Windows configuration interface that provides access to system settings, hardware configuration, network setup, and administrative tools. While Windows Settings app is modern, many advanced features still require Control Panel.

How to Access Control Panel

  • Search: Type "Control Panel" in Start menu search
  • Run Command: control (Win + R)
  • File Explorer: Type "Control Panel" in address bar
  • Right-click Start: Some versions show Control Panel link

View Modes

Category View

Groups items by function - user-friendly but hides advanced options

Large/Small Icons

Shows all Control Panel items alphabetically - faster for power users

Exam Tip: Many utilities ONLY exist in Control Panel, not in Settings app. Know how to navigate both interfaces!

Programs and Features

Run Command: appwiz.cpl

Key Functions

1. Uninstall or Change Programs
  • Remove installed applications properly
  • Modify or repair existing installations
  • View installation date and size
  • Sort by name, publisher, install date, or size
2. Turn Windows Features On or Off
  • Hyper-V: Microsoft's virtualization platform (Pro/Enterprise)
  • Internet Information Services (IIS): Web server
  • Telnet Client: Legacy remote access protocol
  • Windows Subsystem for Linux (WSL): Run Linux distributions
  • .NET Framework: Application runtime versions
  • SMB 1.0/CIFS: Legacy file sharing (security risk - disable if not needed)
3. View Installed Updates
  • See all installed Windows updates with KB numbers
  • Uninstall problematic updates if needed
4. Run Programs in Compatibility Mode
  • Configure programs for previous Windows versions
Exam Tip: This is where you enable/disable Windows features! Requires reboot for most features to take effect.

Device Manager Spotlight

Run Commands: devmgmt.msc or hdwwiz.cpl

Access Methods

  • Control Panel: Hardware and Sound → Device Manager
  • Run Command: devmgmt.msc
  • Right-click Start Menu: Device Manager (Windows 10/11)
  • System Properties: Advanced → Hardware tab → Device Manager

Key Functions

Update Drivers
  • Search automatically for updated driver software
  • Browse computer for driver software (manual install)
  • Right-click device → Update driver
Roll Back Drivers
  • Revert to previous driver version
  • Useful when new driver causes problems
  • Properties → Driver tab → Roll Back Driver
Uninstall Devices
  • Remove device and its driver
  • Option to delete driver software
  • Useful for troubleshooting corrupted drivers
Disable/Enable Devices
  • Temporarily disable hardware without uninstalling
  • Enable previously disabled devices
  • Useful for isolating hardware conflicts
View Hardware Resources
  • IRQ (Interrupt Request) assignments
  • DMA (Direct Memory Access) channels
  • I/O ports and memory addresses
  • View → Resources by type/connection
Scan for Hardware Changes
  • Detect newly connected devices
  • Action menu → Scan for hardware changes

Device Status Indicators

  • Yellow Exclamation Mark (!): Device has a problem or driver issue
  • Red X: Device is disabled
  • Down Arrow: Device is disabled by user
  • No Icon: Device is working properly
Exam Tip: Device Manager is CRITICAL for hardware troubleshooting! Know how to update, roll back, and uninstall drivers.

User Accounts

Run Command: control userpasswords or netplwiz

User Account Management

Change Account Type
  • Standard User: Limited privileges, cannot install software or change system settings
  • Administrator: Full control over the system, install software, change settings

Manage Another Account
  • Create new user accounts
  • Delete user accounts
  • Change account name or password
  • Set up parental controls (Family Safety)
Change User Account Control (UAC) Settings
  • Configure when to be notified about system changes
  • Four UAC levels from Never Notify to Always Notify
  • Balance between security and convenience
Credential Manager
  • Web Credentials: Stored passwords for websites and web apps
  • Windows Credentials: Network credentials, Remote Desktop, and app passwords
  • View, edit, add, or remove saved credentials
  • Backup and restore credentials

User Account Control (UAC) Deep Dive

Four UAC Levels Explained

Level 1: Always Notify (Most Secure)

Notify when programs try to install or make changes AND when I change Windows settings. Screen dims and desktop locks.

  • Maximum security
  • Most intrusive - prompts very frequently
  • Recommended for high-security environments
Level 2: Notify Only When Apps Try to Make Changes (DEFAULT)

Notify only when programs try to make changes, not when I change Windows settings. Screen dims and desktop locks.

  • Default Windows setting
  • Good balance of security and usability
  • Reduces prompts for administrative tasks
  • Most commonly used setting
Level 3: Notify But Don't Dim Desktop

Same as Level 2, but screen doesn't dim and desktop doesn't lock.

  • Less secure - other programs can interfere
  • Faster response time
  • Use only on trusted systems
Level 4: Never Notify (Least Secure - NOT RECOMMENDED!)

Never notify when programs try to install software or make changes.

  • Disables UAC completely
  • Major security risk!
  • Malware can make changes without permission
  • Only use for testing/troubleshooting, then re-enable

Why UAC Matters

  • Prevents Unauthorized Changes: Malware can't silently install
  • Principle of Least Privilege: Users run with standard privileges by default
  • Audit Trail: Logs elevation attempts in Security log
  • Over-the-Shoulder Consent: Prompts for admin password if standard user
Exam Tip: Know the DEFAULT UAC setting is Level 2: "Notify only when apps try to make changes"! This is testable!

Clock and Region

Run Command: timedate.cpl

Date and Time

  • Set Time and Date: Manually adjust system clock
  • Change Time Zone: Select correct time zone and DST settings
  • Internet Time: Synchronize with time server (time.windows.com)
  • Additional Clocks: Display up to 2 additional time zones

Internet Time Synchronization

  • Windows synchronizes time with NTP servers automatically
  • Default server: time.windows.com
  • Can configure custom NTP servers
  • Critical for domain authentication (Kerberos requires accurate time)
  • Default sync interval: Once per week for workstations

Region

  • Format: Date, time, currency, and number format display
  • Location: Determines location-based content
  • Administrative: Language for non-Unicode programs, copy settings to system accounts
Exam Tip: Time sync issues can break domain authentication! Kerberos requires clocks to be within 5 minutes.
Common Issue: Wrong time zone or disabled time sync causes login failures on domain-joined computers.

Ease of Access (Accessibility)

Ease of Access Center

Accessibility features to help users with disabilities use the computer more effectively.

Visual Aids
  • Narrator: Screen reader that reads aloud screen content
  • Magnifier: Enlarges portions of the screen
  • High Contrast Themes: Easier to see for visually impaired users
  • Adjust Screen Brightness: Optimize visual display
Keyboard Aids
  • Sticky Keys: Press modifier keys (Shift, Ctrl, Alt) one at a time instead of simultaneously
  • Filter Keys: Ignore brief or repeated keystrokes
  • Toggle Keys: Sound alerts when Caps Lock, Num Lock, or Scroll Lock pressed
  • On-Screen Keyboard: Virtual keyboard for mouse/touch input
Mouse Aids
  • Mouse Pointer Size/Color: Larger, more visible cursor
  • Mouse Keys: Control mouse pointer with numeric keypad
  • Click Lock: Highlight or drag without holding mouse button
Audio Aids
  • Visual Notifications: Flash screen instead of sounds
  • Mono Audio: Combine stereo to single channel
  • Captions: Show captions for speech
Speech Recognition
  • Control computer using voice commands
  • Dictate text instead of typing
Exam Tip: Sticky Keys activates automatically if you press Shift key 5 times rapidly! Know how to enable/disable accessibility features.
Quick Shortcuts: Win + U opens Ease of Access settings. Win + Plus/Minus activates Magnifier. Win + Ctrl + Enter activates Narrator.

File Explorer Options (Folder Options)

Access: File Explorer → View tab → Options OR Control Panel → File Explorer Options

General Tab

  • Open File Explorer to: Quick access or This PC
  • Browse Folders: Open each folder in same or new window
  • Click Behavior: Single-click or double-click to open
  • Navigation Pane: Show/hide All Folders, expand to current folder

View Tab (CRITICAL for A+ Exam!)

  • Hidden Files and Folders: Show or hide hidden files/folders
  • Hide Extensions for Known File Types: UNCHECK to see file extensions!
  • Hide Protected Operating System Files: Keep checked unless troubleshooting
  • Show Drive Letters: Display drive letters before drive names
  • Launch Folder Windows in Separate Process: Stability vs performance

Search Tab

  • What to Search: Index only vs always search file names and contents
  • Include System Directories: Search system folders
  • Include Compressed Files: Search inside ZIP files

Critical Security Settings

  • Show Hidden Files and Folders: Malware often hides files
  • Show File Extensions: Prevents malware disguised as other file types (virus.txt.exe appears as virus.txt if extensions hidden!)
Exam Tip: Malware frequently uses hidden file attributes and double extensions (file.pdf.exe). ALWAYS show hidden files and file extensions when troubleshooting!

Administrative Tools

Collection of Microsoft Management Console (MMC) snap-ins and system tools for advanced configuration.

Computer Management

compmgmt.msc

  • System Tools: Task Scheduler, Event Viewer, Shared Folders, Local Users and Groups, Performance Monitor, Device Manager
  • Storage: Disk Management
  • Services and Applications: Services, WMI Control
Disk Management

diskmgmt.msc

  • Create, delete, format partitions and volumes
  • Assign drive letters
  • Initialize new disks
  • Convert between MBR and GPT
  • Shrink or extend volumes
Event Viewer

eventvwr.msc

  • Application Log: Application errors and warnings
  • System Log: System component events
  • Security Log: Audit events (login attempts, file access)
  • Setup Log: Installation events
Services

services.msc

  • Start, stop, pause, or restart services
  • Configure startup type: Automatic, Manual, Disabled
  • Set recovery options if service fails
  • Log on as different account
Local Security Policy

secpol.msc (Pro/Enterprise only)

  • Password policies
  • Account lockout policies
  • User rights assignment
  • Security options
Task Scheduler

taskschd.msc

  • Schedule programs or scripts to run automatically
  • Trigger on time, login, or system events
  • Run tasks with elevated privileges
  • View task history and logs
Other Tools
  • Performance Monitor: perfmon.msc
  • Resource Monitor: resmon.exe
  • Memory Diagnostic: Test RAM
  • System Information: msinfo32
