Lab Summary

Key Control Panel Skills Learned

  • Multiple Access Methods: Search, Run commands (Win+R), and File Explorer all provide quick access to Control Panel
  • View Modes: Category view groups related items; Icon views show all utilities alphabetically for faster direct access
  • Run Commands: Professional IT technicians memorize .cpl and .msc commands for instant access to specific utilities
  • Device Manager: Essential tool for viewing hardware, updating drivers, and troubleshooting device conflicts
  • Security Settings: Internet Options, UAC, and File Explorer Options all contain critical security configurations

CompTIA A+ Exam Tips

  • Memorize Run Commands: Know appwiz.cpl, devmgmt.msc, inetcpl.cpl, powercfg.cpl, sysdm.cpl, firewall.cpl
  • UAC Default: Level 2 - "Notify me only when apps try to make changes to my computer"
  • Security Best Practice: Uncheck "Hide extensions for known file types" to prevent malware disguises
  • Device Manager: Yellow exclamation = driver issue; Red X = disabled device; Down arrow = device disabled by user
  • Control Panel vs Settings: Know that Microsoft is migrating features to Settings, but Control Panel still provides advanced options
  • Internet Security Zones: Internet (Medium-high), Local intranet (Medium-low), Trusted (Medium), Restricted (High)

Most Important Run Commands to Memorize

  • appwiz.cpl - Programs and Features (uninstall programs)
  • devmgmt.msc - Device Manager (hardware troubleshooting)
  • sysdm.cpl - System Properties (computer name, domain, hardware profiles)
  • inetcpl.cpl - Internet Options (browser security settings)
  • firewall.cpl - Windows Defender Firewall
  • powercfg.cpl - Power Options (battery and sleep settings)
