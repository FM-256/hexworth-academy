System Settings Configuration

  • Navigate to Settings > System > Display
  • Change scale from 100% to 125%, then back to original
  • Observe how windows and text resize
Record your original scaling value first
Expected: Display scaling changes take effect immediately
  • Enable Night Light in Display settings
  • Set schedule for sunset to sunrise
  • Adjust color temperature slider
Expected: Screen takes on a warmer tone when enabled
  • Navigate to System > Storage
  • Identify the largest category consuming space
  • Enable Storage Sense if not already enabled
  • Review what Storage Sense will automatically clean
Expected: Visual breakdown of storage by category
  • Go to System > About
  • Record the following:
    • Device name
    • Processor
    • Installed RAM
    • Windows Edition
    • Version number

  • Navigate to System > Notifications
  • Review which apps can send notifications
  • Turn off notifications for one non-essential app
  • Explore notification priority settings
Expected: Individual app notification controls available

Network & Internet Configuration

  • Navigate to Network & Internet
  • Check your current connection type (Wi-Fi/Ethernet)
  • Note your network name and status
  • Review connection properties
Expected: Active connection shows as "Connected"
  • Find your current IP address in Network Settings (click on your active connection > Properties)
  • Compare: Open Command Prompt and run ipconfig
  • Verify the IPv4 address matches in both locations
Expected: IP addresses match in Settings and Command Prompt
  • Navigate to Network & Internet > Proxy
  • Verify automatic proxy detection is on
  • Review manual proxy setup options (do not change)
Do NOT change proxy settings on school/work networks
Expected: "Automatically detect settings" is typically ON
  • Navigate to Network & Internet > Data usage
  • View which apps have used the most data in the last 30 days
  • Identify the top 3 data-consuming applications
Expected: List of apps sorted by data consumption

Accounts & Security

  • Navigate to Accounts > Sign-in options
  • List all available sign-in methods on your system
  • Identify which require hardware (fingerprint reader, IR camera for facial recognition)
  • Note which methods are configured vs. available
Expected: PIN, Password, and optionally Windows Hello options
  • In Accounts > Your info, determine if your account is Local or Microsoft
  • Navigate to Accounts > Family & other users (or Other users)
  • Check if you have Administrator privileges
Expected: Account type and privilege level clearly indicated
  • Navigate to Privacy & Security > Windows Security
  • Click "Open Windows Security"
  • Verify Virus & threat protection is active
  • Check when the last scan occurred
  • Review the protection history
Expected: Green checkmarks indicate protection is active
  • Navigate to Windows Update
  • Check for updates (do not install during class unless permitted)
  • View update history
  • Explore advanced options (pause updates, delivery optimization)
Ask instructor before installing updates during class
Expected: Current update status and available options displayed

Documentation Challenge

Settings vs Control Panel Comparison

Windows Settings is the modern interface, while Control Panel is the legacy interface. Many tasks can be accomplished in both locations. Practice finding these common tasks in both interfaces:

Task Settings Path Control Panel Path
Change display resolution System > Display Appearance and Personalization > Display
Add a printer Bluetooth & Devices > Printers & scanners Hardware and Sound > Devices and Printers
Uninstall a program Apps > Installed apps Programs > Programs and Features
Change power plan System > Power Hardware and Sound > Power Options

Verification Checklist - Can you find each task in BOTH locations?

Lab Summary

Key Takeaways

  • Settings App Organization: Settings is organized into major categories (System, Network, Accounts, etc.) with subcategories for specific configurations
  • Dual Interfaces: Many configuration tasks can be performed in both Settings and Control Panel, but Microsoft is gradually moving everything to Settings
  • Admin Access Required: Some settings require administrator privileges to modify
  • Real-time Changes: Most settings take effect immediately without requiring a restart
  • System Information: Settings > System > About is the quickest way to find device specifications and Windows version

CompTIA A+ Exam Tips

  • Know both interfaces: The A+ exam may ask about both Settings and Control Panel paths
  • Windows versions: Be aware of differences between Windows 10 and Windows 11 Settings layouts
  • Common tasks: Memorize Settings paths for common support tasks: Display, Network status, Storage, Windows Update, Device Manager
  • Troubleshooting: Know where to find diagnostic information: System > About for specs, Network status for connectivity, Storage for disk space
  • Security settings: Understand where to find Windows Security, Windows Update, and sign-in options
