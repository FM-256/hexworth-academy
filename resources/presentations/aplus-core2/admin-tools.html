Overview - What Are Administrative Tools?

Administrative Tools are a collection of advanced system management utilities built into Windows for IT professionals and power users.

How to Access:

  • Windows 10: Control Panel > Administrative Tools
  • Windows 11: Now called "Windows Tools"
  • Quick Access: Search for "Windows Tools" or specific tool names
Key Characteristics:
  • Most tools use MMC (Microsoft Management Console) framework
  • Run commands typically end in .msc extension
  • Require administrator privileges for full functionality
Know the difference between Windows 10 "Administrative Tools" and Windows 11 "Windows Tools" - same tools, different name!

Microsoft Management Console (MMC)

What is MMC?

MMC is a framework that hosts administrative snap-ins. It's not a tool itself, but a container for other tools.

Run Command: mmc.exe

You can create custom consoles by adding multiple snap-ins to a single MMC window!

Common MMC Snap-ins:

  • devmgmt.msc - Device Manager (hardware management)
  • diskmgmt.msc - Disk Management (partition and drive management)
  • compmgmt.msc - Computer Management (all-in-one console)
  • services.msc - Services (background process management)
Understand that MMC is the host framework for snap-ins. When you open Device Manager or Disk Management, you're using MMC snap-ins!

Computer Management

compmgmt.msc

Quick Access: Right-click Start button > Computer Management

Three Main Sections:

1. System Tools

  • Event Viewer - View system logs
  • Shared Folders - Network share management
  • Local Users and Groups - Account management
  • Performance - System monitoring
  • Device Manager - Hardware devices
  • Task Scheduler - Automated tasks

2. Storage

  • Disk Management

3. Services and Applications

  • Services
  • WMI Control
Computer Management is your one-stop shop for many administrative tasks. Know that it consolidates multiple tools in one interface!

Event Viewer

eventvwr.msc

Purpose:

View detailed system, application, and security logs for troubleshooting and auditing.

Four Main Log Types:

  • Application: Software events (crashes, errors, warnings)
  • Security: Audit events (logon attempts, file access, policy changes)
  • Setup: Installation and update events
  • System: Operating system and driver events

Event Severity Levels:

Information
Warning
Error
Critical
Event Viewer should be your FIRST stop when troubleshooting mysterious system issues, crashes, or security incidents!

Event Viewer - Using Logs

Key Features:

  • Filter logs by level, date, source, and Event ID
  • Create custom views for frequently monitored events
  • Export logs in .evtx format for analysis or archiving

Common Event IDs to Know:

Event ID Log Type Meaning
4624 Security Successful user logon
4625 Security Failed logon attempt
6005 System Event log started (system boot)
6006 System Event log stopped (clean shutdown)
41 System Kernel-Power (unexpected shutdown)
Event ID 41 (Kernel-Power) indicates unexpected shutdown - often hardware issues like power supply or overheating!

Disk Management

diskmgmt.msc

Purpose:

View and manage all drives, partitions, and volumes on the system.

Key Functions:

  • Initialize new disks (choose GPT vs MBR partition style)
  • Create, delete, and format partitions
  • Extend volumes (add space to existing partition)
  • Shrink volumes (free up space from partition)
  • Change drive letters and paths
  • Convert between Basic and Dynamic disks

Common Status Indicators:

  • Healthy - Working normally
  • Online - Dynamic disk available
  • Failed - Disk error
  • Offline - Not accessible
You CANNOT extend a volume into non-contiguous (non-adjacent) space. The free space must be directly after the partition!

Task Scheduler

taskschd.msc

Purpose:

Automate tasks to run on schedules or in response to triggers.

Trigger Types:

Time-Based Triggers

  • One time
  • Daily
  • Weekly
  • Monthly

Event-Based Triggers

  • At startup
  • At user logon
  • On specific Event ID
  • On idle

Action Types:

  • Start a program (most common - run .exe, script, batch file)
  • Send an email (deprecated in newer Windows versions)
  • Display a message (deprecated in newer Windows versions)

Conditions:

Optional requirements: Idle time, AC power, network available

Malware often uses Task Scheduler for persistence! Always check scheduled tasks when investigating infections.

Services Console

services.msc

Purpose:

Manage Windows services (background processes) that run without user interaction.

Service Startup Types:

  • Automatic - Starts at system boot
  • Automatic (Delayed Start) - Starts after boot completes
  • Manual - Starts when needed by application or user
  • Disabled - Cannot start at all

Service Status:

  • Running - Currently active
  • Stopped - Not running
  • Paused - Temporarily suspended

Common Important Services:

  • Print Spooler: Manages print jobs
  • Windows Update: Automatic updates
  • DNS Client: DNS resolution caching
  • DHCP Client: IP address assignment
Disable unused services to reduce attack surface and improve performance. Always research a service before disabling it!

Local Users and Groups

lusrmgr.msc

⚠️ Edition Requirement: Available on Windows Pro, Enterprise, and Education only. NOT available on Windows Home!

Purpose:

Manage local user accounts and group memberships on the computer.

Key Functions:

  • Create, modify, and delete local user accounts
  • Set passwords and password requirements
  • Add users to groups for permission management
  • Enable/disable accounts
  • Set account expiration dates

Built-in Groups:

  • Administrators: Full system control
  • Users: Standard user permissions
  • Guests: Minimal permissions (often disabled)
  • Remote Desktop Users: Can connect via RDP
  • Power Users: Legacy group (limited use in modern Windows)
Remember: lusrmgr.msc is NOT available in Windows Home edition! You must use Settings > Accounts instead.

Local Security Policy

secpol.msc

⚠️ Edition Requirement: Available on Windows Pro, Enterprise, and Education only. NOT available on Windows Home!

Purpose:

Configure security settings and policies for the local computer.

Key Policy Areas:

  • Account Policies: Password requirements, account lockout policies
  • Local Policies: Audit policies, user rights assignments, security options
  • Windows Firewall: Firewall rules and settings
  • Advanced Audit Policy: Detailed auditing configuration

Common Password Policy Settings:

  • Minimum password length (e.g., 8 characters)
  • Password complexity requirements (upper, lower, numbers, symbols)
  • Password history (prevent reuse of X previous passwords)
  • Maximum password age (force password changes)
  • Account lockout threshold (lock after X failed attempts)
Domain Group Policy overrides Local Security Policy! If the computer is domain-joined, domain policies take precedence.

Group Policy Editor

gpedit.msc

⚠️ Edition Requirement: Available on Windows Pro, Enterprise, and Education only. NOT available on Windows Home!

Purpose:

Configure system and user policies that control Windows behavior and features.

Two Main Sections:

Computer Configuration

System-wide settings that apply regardless of who logs in

  • Windows Settings
  • Administrative Templates

User Configuration

Settings that apply to specific users

  • Windows Settings
  • Administrative Templates

Common Policy Uses:

  • Disable removable storage (USB drives)
  • Configure Windows Update behavior
  • Set default wallpaper or lock screen
  • Disable access to Control Panel or Settings
  • Configure password policies
  • Restrict software installation
gpedit.msc is NOT available on Windows Home edition! This is a common exam question - know the edition limitations!

Performance Monitor

perfmon.msc

Purpose:

Real-time and historical system performance monitoring for diagnosing bottlenecks.

Key Performance Counters:

Counter What It Measures High Value Indicates
% Processor Time CPU usage CPU bottleneck
Available MBytes Free RAM Low = memory shortage
Disk Queue Length Pending disk I/O Storage bottleneck
Pages/sec Memory paging rate Insufficient RAM

Additional Tools:

  • Data Collector Sets: Record performance data over time for analysis
  • Resource Monitor: Detailed real-time view of CPU, Memory, Disk, Network
High Pages/sec consistently over time = system needs more RAM! Memory paging to disk is much slower than using physical RAM.

System Configuration

msconfig

Note: Unlike other administrative tools, this one does NOT end in .msc - it's just msconfig!

Purpose:

Configure boot options and startup behavior for troubleshooting.

Five Main Tabs:

  1. General: Startup selection (Normal, Diagnostic, Selective boot)
  2. Boot: Safe mode options, boot timeout, advanced options (number of processors, max memory)
  3. Services: Enable/disable services, option to hide Microsoft services
  4. Startup: Opens Task Manager startup tab (in Windows 10/11)
  5. Tools: Quick access to common administrative tools

Common Use Case: Clean Boot

Clean Boot Process:

  1. Services tab: Hide Microsoft services, Disable all
  2. Startup tab: Open Task Manager, disable all startup items
  3. Restart and test if issue persists
  4. Re-enable services/startup items one by one to identify culprit
Use msconfig for clean boot troubleshooting when apps conflict or system behaves strangely!
