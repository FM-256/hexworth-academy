System Configuration (msconfig)

Purpose: Configure startup and boot options for troubleshooting and system optimization

Five Main Tabs:

1. General Tab

  • Normal startup: Load all device drivers and services
  • Diagnostic startup: Load basic devices and services only (Safe Mode equivalent)
  • Selective startup: Choose what to load (custom troubleshooting)

2. Boot Tab

  • Safe boot options (Minimal, Alternate shell, Network, Active Directory repair)
  • Boot timeout configuration
  • Advanced boot options (number of processors, maximum memory)

3. Services Tab

  • Enable/disable services at startup
  • "Hide all Microsoft services" checkbox for clean boot troubleshooting

4. Startup Tab

Links to Task Manager in Windows 10/11

5. Tools Tab

Quick access to other system utilities

Key Use Case: Clean boot troubleshooting - disable third-party services to identify conflicts causing system instability or slow performance.
Diagnostic startup is essentially Safe Mode with minimal drivers! Remember this equivalence for exam questions.

System Information (msinfo32)

Purpose: Provides comprehensive hardware and software information in a structured, exportable format

Main Categories:

System Summary

  • OS name and version
  • Processor (CPU) make, model, and speed
  • Installed physical RAM
  • BIOS version and date
  • System manufacturer and model
  • Windows directory location

Hardware Resources

  • Conflicts/Sharing
  • DMA (Direct Memory Access)
  • IRQs (Interrupt Requests)
  • I/O addresses
  • Memory addresses

Components

  • Display (graphics cards)
  • Sound devices
  • Network adapters
  • Storage devices
  • USB devices

Software Environment

  • System drivers loaded at boot
  • Running services
  • Startup programs
  • Windows Error Reporting history
Export Capability: Save system information as .nfo or .txt file for documentation or remote troubleshooting support.
Best tool for gathering complete system specifications! Use this when you need detailed hardware/software inventory or are diagnosing driver/hardware conflicts.

DirectX Diagnostic Tool (dxdiag)

Purpose: Diagnose issues related to DirectX, graphics, sound, and input devices - essential for multimedia troubleshooting

Four Main Tabs:

1. System Tab

  • Computer name and operating system
  • Processor and memory
  • DirectX version installed
  • System manufacturer and model
  • BIOS information

2. Display Tab

  • Graphics card name and manufacturer
  • Driver version and date
  • Current display mode and resolution
  • DirectX features status (DirectDraw, Direct3D, AGP Texture Acceleration)
  • Notes section shows any detected problems

3. Sound Tab

  • Audio device name
  • Sound driver details
  • Audio acceleration settings
  • Problem detection

4. Input Tab

  • Game controllers
  • Input devices
  • DirectInput status
  • Device drivers
Export Feature: Click "Save All Information" to export complete diagnostic data to a text file - useful for remote support or documentation.
Use dxdiag for graphics and sound troubleshooting! If a user reports gaming issues, video playback problems, or audio glitches, this is your go-to tool.

Registry Editor (regedit)

Purpose: View and edit the Windows Registry - the central database storing system and application configuration settings

Five Root Keys (Hives):

HKEY_CLASSES_ROOT (HKCR)
File associations, COM object registration, file type settings
HKEY_CURRENT_USER (HKCU)
Current logged-in user's preferences and settings (desktop, environment variables)
HKEY_LOCAL_MACHINE (HKLM)
System-wide settings affecting all users (hardware, drivers, installed software)
HKEY_USERS (HKU)
All loaded user profiles on the system
HKEY_CURRENT_CONFIG (HKCC)
Current hardware profile information
Export/Import: Right-click any key and select "Export" to create a backup .reg file before making changes. You can restore by importing the file later.
HKLM\SOFTWARE contains installed program information! Know this path for exam questions about finding software installation details.
Registry errors can break Windows and prevent booting! Always backup before editing, and only modify registry entries if you know exactly what you're doing.

Task Manager (taskmgr)

Access Methods: Ctrl+Shift+Esc | Ctrl+Alt+Del | Right-click taskbar

Seven Main Tabs (Windows 10/11):

Processes

  • Running applications
  • Background processes
  • Windows processes
  • CPU, Memory, Disk, Network usage per process
  • Right-click to "End task"

Performance

  • Real-time graphs: CPU, Memory, Disk, Network
  • GPU usage (Windows 10+)
  • CPU speed and core count
  • Memory composition
  • Network throughput

App History

  • Resource usage by application
  • CPU time
  • Network data usage

Startup

  • Programs that run at Windows startup
  • Enable/disable startup items
  • Startup impact rating
  • Publisher information

Users

  • Currently logged-in users
  • Resource usage per user
  • Disconnect or sign out users

Details

  • Advanced process information
  • Process ID (PID)
  • Set priority
  • Set affinity (CPU cores)

Services

  • All Windows services
  • Start, stop, restart services
  • Links to full Services console
Use "End task" for unresponsive programs! Task Manager is your first-line tool for basic performance monitoring and killing frozen applications.

Resource Monitor (resmon)

Purpose: Real-time detailed resource monitoring - provides more granular information than Task Manager's Performance tab

Four Main Tabs:

1. CPU Tab

  • Process CPU usage with detailed breakdown
  • Associated handles (files, registry keys) per process
  • Loaded modules (DLLs) per process
  • Services running under each process
  • Filter by checking a process to see only its resources

2. Memory Tab

  • Physical memory usage by process
  • Working set (active memory)
  • Commit size (reserved memory)
  • Hard faults per second
  • Memory composition (Free, In Use, Modified, Standby, Cached)

3. Disk Tab

  • Read/write activity by process
  • Which specific files are being accessed
  • Disk queue length
  • Storage performance graphs

4. Network Tab

  • Network activity per process
  • Active TCP connections
  • Listening ports
  • Remote addresses
Key Feature: Check a process in any tab to filter all other tabs to show only that process's resource usage - excellent for drilling down into what a specific program is doing!
Resource Monitor is MORE DETAILED than Task Manager's Performance tab! Use it when you need to see exactly which files a process is accessing or which network connections it has open.

Disk Management Tools

Disk Defragmenter (dfrgui)

Purpose: Reorganizes fragmented data on hard disk drives to improve performance

  • How it works: Consolidates scattered file fragments so data is stored contiguously
  • For HDDs: Significantly improves read/write performance and reduces mechanical wear
  • Scheduled optimization: Windows 10/11 automatically optimizes drives weekly by default
  • Manual defragmentation: "Analyze" first to see if defragmentation is needed
Do NOT defragment SSDs! SSDs use TRIM instead, which Windows handles automatically. Defragmenting an SSD wastes write cycles and reduces its lifespan.

Check Disk (chkdsk)

Purpose: Scans file system for errors and bad sectors, repairs logical file system errors

Common Commands:

  • chkdsk C: - Scan only (no repairs, read-only)
  • chkdsk C: /F - Fix file system errors (requires exclusive access)
  • chkdsk C: /R - Locate bad sectors and recover readable data (implies /F)
  • chkdsk C: /F /R - Full scan with error fixing and bad sector recovery
System Drive: chkdsk on the boot drive (C:) requires a restart. Windows will run chkdsk before the OS loads at next boot.
Remember: Defrag for HDDs only, NOT SSDs! SSDs use TRIM. Also know that chkdsk /R includes the functionality of /F (you don't need both).

Diskpart - Command-Line Disk Management

Purpose: Powerful command-line utility for disk partitioning and management - more advanced than GUI Disk Management

Common Diskpart Commands:

Viewing Information

  • list disk - Show all physical disks
  • list volume - Show all volumes (partitions)
  • list partition - Show partitions on selected disk
  • detail disk - Show details of selected disk

Selecting and Manipulating

  • select disk 0 - Select disk number 0 (first disk)
  • select volume D - Select volume by drive letter
  • clean - WIPES ENTIRE DISK (removes all partitions and data)
  • create partition primary - Create a primary partition
  • format fs=ntfs quick - Quick format as NTFS
  • format fs=fat32 quick - Quick format as FAT32
  • assign letter=D - Assign drive letter D to selected volume
  • active - Mark partition as active (bootable)

Typical Use Case: Creating Bootable USB

diskpart
list disk (identify USB drive number)
select disk 1 (USB drive - BE CAREFUL!)
clean
create partition primary
select partition 1
active
format fs=fat32 quick
assign
exit
The "clean" command DELETES ALL DATA on the selected disk! Double-check disk numbers with "list disk" before proceeding. There is NO undo!
Know that diskpart's "clean" command wipes the entire disk - use it carefully! Also remember diskpart is essential for creating bootable USB drives for Windows installations.

Additional System Tools

System File Checker (sfc)

Command: sfc /scannow

  • Scans all protected system files for integrity violations
  • Replaces corrupted files with cached correct copies from C:\Windows\System32\dllcache
  • Must run as Administrator
  • Results logged to CBS.log (Component-Based Servicing log)
  • Takes 15-30 minutes typically

When to use: System instability, crashes, DLL errors, corrupted Windows files

DISM (Deployment Image Servicing and Management)

Command: DISM /Online /Cleanup-Image /RestoreHealth

  • Repairs the Windows component store (system image)
  • Downloads replacement files from Windows Update if needed
  • Run BEFORE sfc if sfc fails - DISM fixes the source files that sfc uses
  • Must run as Administrator
  • Requires internet connection for file downloads
  • Can take 20-45 minutes

When to use: When sfc reports corruption it cannot fix, or preventatively before running sfc

Windows Memory Diagnostic (mdsched)

Command: mdsched or search "Windows Memory Diagnostic"

  • Tests RAM (random access memory) for hardware errors
  • Runs two passes by default (Basic test)
  • Requires restart - runs before Windows loads
  • Extended test available (press F1 during test)
  • Results shown after Windows boots and saved in Event Viewer

When to use: Random crashes, blue screens, system freezes, or suspected RAM issues

Critical sequence: Run DISM FIRST, then sfc! DISM repairs the component store that sfc uses as its source. If sfc fails, run DISM and then re-run sfc.
