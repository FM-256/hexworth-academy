Exercise 2: DirectX Diagnostic (dxdiag)

▼
1 Launch and Explore
Open DirectX Diagnostic Tool: Press Win+R, type dxdiag, and press Enter. Verify that the information on the System tab matches what you found in msinfo32.
2 Display Information
Click on the Display tab (or Display 1 if you have multiple monitors) to view graphics information.

Exercise 4: Resource Monitor (resmon)

▼
1 Launch and Compare
Open Resource Monitor: Press Win+R, type resmon, and press Enter. Compare the CPU information displayed here to what you saw in Task Manager.
2 Identify Top Processes
Navigate through each tab (CPU, Memory, Disk, Network) and identify the top resource consumers.

Exercise 5: Disk Health Check

▼
1 Disk Defragmenter
Open Optimize Drives: Press Win+R, type dfrgui, and press Enter.
Warning: Do NOT run optimization during this lab. We are only viewing the current status.
2 Check Disk (Read Only)
Open Command Prompt as Administrator (search for "cmd", right-click, select "Run as administrator"). Run the following command:
chkdsk C:
Note: This command only reads the disk. The /F and /R parameters are for repair and should not be used during this lab.

Exercise 6: System Configuration (msconfig)

▼
1 Explore Boot Options
Open System Configuration: Press Win+R, type msconfig, and press Enter.
Warning: DO NOT change any settings in msconfig! Changing boot options can prevent Windows from starting properly.
2 Review Services
Click on the Services tab. Check the "Hide all Microsoft services" checkbox to see only third-party services.
Note: Remember to uncheck "Hide all Microsoft services" before closing msconfig!

Exercise 7: Command-Line Tools

▼
1 System File Checker (Read Only)
Open Command Prompt as Administrator. Run the following command:
sfc /verifyonly
Note: The /verifyonly parameter scans system files but doesn't repair them. This scan may take 5-10 minutes.

In Command Prompt, run the following command (Administrator privileges not required):
