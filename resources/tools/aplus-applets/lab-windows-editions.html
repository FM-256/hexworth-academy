Exercise 1: Identify Your Windows Edition

Not Started

In this exercise, you'll use four different methods to identify your Windows edition. Each method provides slightly different information and is useful in different troubleshooting scenarios.

Method 1: Settings App

  1. Press Windows + I to open Settings
  2. Click System in the left sidebar
  3. Scroll down and click About
  4. Look for "Windows specifications" section
  5. Note the Edition field
Expected Result: You should see "Edition: Windows XX [Home/Pro/Enterprise/Education]"

Method 2: winver Command

  1. Press Windows + R to open Run dialog
  2. Type winver and press Enter
  3. A dialog box will appear with "About Windows"
  4. The second line shows your edition (e.g., "Microsoft Windows Pro")
  5. Note the complete version and build number as well
Expected Result: A popup window titled "About Windows" with edition information

Method 3: systeminfo Command

  1. Press Windows + R, type cmd, and press Enter
  2. In the Command Prompt, type systeminfo and press Enter
  3. Wait for the system to gather information (may take 10-30 seconds)
  4. Look for "OS Name:" line near the top
  5. Note the complete operating system name and edition
Expected Result: Detailed system information including "OS Name: Microsoft Windows XX Pro"

Method 4: System Information (msinfo32)

  1. Press Windows + R to open Run dialog
  2. Type msinfo32 and press Enter
  3. The System Information window will open
  4. In the right pane, locate "OS Name"
  5. Note the complete information including edition and architecture
Expected Result: System Information window with detailed OS specifications

Exercise 2: Feature Availability Check

Not Started

Now that you know your Windows edition, verify which features are actually available on your system. Different editions have different capabilities.

Feature How to Check Available on My System?
BitLocker Drive Encryption Control Panel → System and Security → BitLocker Drive Encryption
Group Policy Editor Windows + R → type gpedit.msc → Enter
Hyper-V Settings → Apps → Optional Features → More Windows features → Look for Hyper-V
Remote Desktop (Host) Settings → System → Remote Desktop
Windows Sandbox Settings → Apps → Optional Features → More Windows features → Look for Windows Sandbox

Exercise 3: Edition Comparison Scenarios

Not Started

Apply your knowledge by determining which Windows edition is needed for each scenario. Think about the features required and which edition provides them.

Scenario 1: A small business needs to join 20 computers to a corporate domain for centralized authentication and management. Which is the minimum edition required?
Scenario 2: A healthcare facility needs to set up a patient check-in kiosk that only runs a single application and locks down access to other features. Which edition supports Assigned Access (Kiosk Mode)?
Scenario 3: A government agency requires BitLocker encryption for data security AND DirectAccess for always-on VPN connectivity. Which edition provides both features?
Scenario 4: A home user wants to browse the web, watch videos, and use Microsoft Office. They don't need domain join or business features. Which edition is most appropriate?
Scenario 5: A video production workstation needs to support 4 physical CPU sockets and 5TB of RAM for rendering. Which edition is required?

Lab Summary

Key Takeaways

  • Multiple Methods: There are several ways to identify your Windows edition - Settings, winver, systeminfo, and msinfo32
  • Edition Matters: Different Windows editions provide different features and capabilities
  • Home Limitations: Home edition lacks domain join, BitLocker, Group Policy, Remote Desktop host, and Hyper-V
  • Pro for Business: Pro edition is the minimum requirement for business features like domain join and BitLocker
  • Enterprise Exclusive: Only Enterprise edition provides DirectAccess and Long-Term Servicing Channel (LTSC)
  • Workstation Power: Pro for Workstations supports up to 4 CPU sockets and 6TB RAM for high-performance scenarios
