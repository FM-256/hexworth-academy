🔬 Cumulative Lab Series

Progressive hands-on labs using Cisco Packet Tracer. Each lab builds upon the previous one, creating a complete enterprise network. Students develop ONE network throughout the course, adding new technologies incrementally.

🎯 Pedagogical Approach

Why Cumulative Labs? Instead of starting fresh each week, students progressively enhance their existing network topology. This mirrors real-world network evolution and helps students understand how different technologies integrate together.

🏗️
Lab 1: Static Routes
Foundation Complete
Build the base enterprise network topology with 12 devices across Edge, Core, Distribution, and Access layers. Configure IP addressing and static routes.
  • 1 Edge Router, 6 Switches
  • 4 VLANs (10, 20, 30, 40)
  • Hierarchical design (3-tier)
  • Static routing configuration
  • End-to-end connectivity testing
View Lab Guide
🏷️
Lab 2: Add VLANs
Builds on Lab 1 Complete
Segment the existing network with VLANs, configure trunk links with 802.1Q tagging, and implement inter-VLAN routing using SVIs.
  • Create VLANs on all switches
  • Configure access & trunk ports
  • 802.1Q tagging implementation
  • Native VLAN configuration
  • Inter-VLAN routing with SVIs
View Lab Guide
🌳
Lab 3: Add STP
Builds on Lab 2 Complete
Add redundant links for fault tolerance and configure Spanning Tree Protocol to prevent loops. Manually configure Root Bridge and implement RSTP.
  • Add redundant switch links
  • Configure RSTP (rapid-pvst)
  • Set Root Bridge priorities
  • Enable PortFast & BPDU Guard
  • Test failover scenarios
View Lab Guide
🔄
Lab 4: Replace with OSPF
Builds on Lab 3 Complete
Remove static routes and implement multi-area OSPF for dynamic routing. Configure Areas 0, 10, and 20 with proper hierarchy.
  • Remove all static routes
  • Configure multi-area OSPF
  • Set Router IDs with loopbacks
  • Adjust reference bandwidth
  • Verify neighbor relationships
View Lab Guide
⚡
Lab 5: Add EIGRP
Builds on Lab 4 Complete
Add remote branch running EIGRP and implement route redistribution between OSPF and EIGRP. Compare routing protocols and optimize with route filtering.
  • Add remote branch topology
  • Configure EIGRP routing
  • Implement redistribution
  • Configure route filtering
  • Compare OSPF vs EIGRP
View Lab Guide
🎯
Lab 6: Advanced Features
Capstone - Builds on Lab 5 Complete
Complete the enterprise network with HSRP gateway redundancy, DHCP for dynamic addressing, ACLs for security, and SNMP monitoring. The final comprehensive lab!
  • Configure HSRP (First-Hop Redundancy)
  • Set up DHCP server
  • Implement ACLs for security
  • Enable SNMP monitoring
  • Complete enterprise simulation

🔧 Lab Troubleshooting Guides

Comprehensive troubleshooting guides for each cumulative lab. When your lab breaks, don't restart - use these guides to diagnose and fix issues systematically. Each guide covers common problems, verification commands, and solutions.

🎯 Troubleshooting Philosophy

"If you fix the problem without rebuilding the lab, you did it the right way."

Every issue you encounter is a learning opportunity. These guides help you develop the systematic troubleshooting skills that network engineers use in production environments. Don't restart your lab - troubleshoot it!

  • IP address mismatches

  • SVI configuration issues
  • Missing/wrong subnet masks
  • Layer 2 vs Layer 3 switch modes
