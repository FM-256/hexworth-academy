## 🔄 How to Use Version Control Going Forward

### Daily Workflow

```bash
# Navigate to project
cd "/home/eq/Ai content creation/network-essentials"

# Make changes to files
# ... edit presentations, labs, simulator, etc. ...

# Check what changed
git status
git diff

# Stage changes
git add <files-you-changed>

# Commit with clear message
git commit -m "Add OSPF visualization to simulator"

# Verify commit
git log --oneline
```

### Before Risky Changes

```bash
# Create safety backup branch
git checkout -b backup-before-major-refactor

# Switch back to main
git checkout main

# Now make your risky changes
# If something goes wrong:
git checkout backup-before-major-refactor
```

### Weekly Backup Routine

```bash
# Create dated backup branch
git branch backup-$(date +%Y%m%d)

# Example output: backup-20251202
```
